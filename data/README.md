# Study data

The analysis script expects the file `BASE PREVALENCIA 15 JULIO .xlsx` (worksheet
`1 HEMI`) in the project directory. It contains individual clinical data and is
not publicly released. Access was approved by CEISH-UCE (017-CEISH.UCE.2021)
and is subject to Ecuador's Organic Law on Personal Data Protection. The data
are available upon reasonable request to the corresponding author.
